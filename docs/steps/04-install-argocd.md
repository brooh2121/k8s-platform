# Шаг 4. Установка ArgoCD

Скрипт: `scripts/04-install-argocd.sh`

## Назначение

Установить `ArgoCD` в namespace `argocd`, чтобы дальше управлять приложениями через GitOps. После установки сервис `argocd-server` переводится в тип `LoadBalancer`, и `MetalLB` выделяет ему внешний IP.

## Предварительные условия

- выполнены шаги 0-3: VM, Kubernetes, `Flannel`, `MetalLB`;
- на хосте доступен `multipass`;
- мастер-нода называется `k8s-master`.

## Что делает скрипт

1. Удаляет старый CRD `applicationsets.argoproj.io`, если он уже есть. Это снижает риск конфликта при повторной установке.
2. Создает namespace `argocd` идемпотентно (`create` + `apply`).
3. Скачивает официальный манифест `ArgoCD` со стабильной ветки на мастер-ноду в `/tmp/argocd-install.yaml`.
4. Заменяет образ Redis в манифесте на `redis:7.2-alpine`. Это локальный обход проблем с недоступным или неподходящим образом Redis из исходного манифеста.
5. Применяет манифест через `kubectl apply --server-side --force-conflicts`. Server-Side Apply нужен из-за большого размера CRD.
6. Ждет, пока все pod'ы в namespace `argocd` перейдут в `Running`.
7. Меняет тип сервиса `argocd-server` на `LoadBalancer`.
8. Пытается прочитать внешний IP от `MetalLB` и начальный пароль администратора из секрета `argocd-initial-admin-secret`.

## Результат

В конце скрипт печатает:
- IP-адрес `LoadBalancer` (если `MetalLB` уже выдал адрес);
- логин `admin`;
- начальный пароль из секрета `argocd-initial-admin-secret`.

На этом этапе UI `ArgoCD` доступен по IP сервиса. Доступ по имени `argocd.local` настраивается отдельно на шаге 6.

Следующий учебный блок по `ArgoCD` - преднастройка и связка с GitLab CI/CD. Это еще не сделано.

## Важные замечания

- источник манифеста - `stable`, версия `ArgoCD` не зафиксирована в репозитории;
- патч Redis выполняется через `sed` по тексту манифеста, это учебный обход, а не постоянная политика образов;
- ожидание готовности считает pod'ы в статусе `Running`, но не проверяет `Ready`;
- если IP еще не появился, поле адреса может быть пустым, это не всегда означает сбой установки.
